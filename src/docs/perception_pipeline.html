From RGB frame to /qr_command

The perception pipeline implemented by qr_detector_node.py — a single ROS 2 callback that turns an OAK-D Pro RGB frame into at most one validated, debounced QR command per cycle. Includes a CLAHE → adaptive-threshold fallback, a spatial filter (largest bbox wins), and a per-command cooldown.

ROS 2 Jazzy OpenCV 4.6 OAK-D Pro RGB detection_rate_hz = 10.0 min_bbox_area = 500 px² cooldown_sec = 1.0

02 · RATE LIMIT

Drop frames to detection_rate_hz

guard

The camera ships frames faster than we need to decode. The first line of image_callback early-returns if the previous decode ran less than 1 / detection_rate_hz seconds ago.

if now - self.last_detection_time < self.detection_period:
    return
self.last_detection_time = now

04 · PREPROCESS

Grayscale + CLAHE contrast enhancement

primary path

Contrast Limited Adaptive Histogram Equalisation rescues QR decoding at oblique angles and under uneven illumination.

gray     = cv2.cvtColor(cv_image, cv2.COLOR_BGR2GRAY)
clahe    = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
enhanced = clahe.apply(gray)
enhanced grayscale

06 · FALLBACK

Adaptive Gaussian thresholding

degraded codes

If CLAHE alone didn't find a QR, re-run detection on a binarised image. This recovers partial or low-contrast codes that the primary path missed.

thresh = cv2.adaptiveThreshold(
    enhanced, 255,
    cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
    cv2.THRESH_BINARY,
    blockSize=11, C=2,
)
detections = self._detect_qr_codes(thresh)
still empty → return (no publish)
07 · MEASURE

Compute bounding-box area per detection

distance proxy

Area of the 4-corner polygon is our proxy for distance — a closer QR fills more pixels. Cast to float32 is required by OpenCV 4.6 (Jazzy default); float64 raises (-215) depth == CV_32F || CV_32S.

bbox_points = np.asarray(points[i], dtype=np.float32)
bbox_area   = cv2.contourArea(bbox_points)

09 · SPATIAL FILTER

Closest QR wins (max bbox area)

tiebreaker

If several valid QRs are in the frame at once, pick the one occupying the most pixels. Resolves the "simultaneous detections" edge case deterministically.

best_command, best_area = max(valid_detections, key=lambda x: x[1])
10 · COOLDOWN

Per-command debounce (1.0 s)

de-bounce

A QR card held in the frame for many frames must only fire its command once. We track the last publish time per command and early-return if we're inside the window.

last_time = self.last_command_time.get(best_command, 0.0)
if now - last_time < self.cooldown_sec:
    return
